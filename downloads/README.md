- `cyber-university-taqdimot.pdf` — 14 slaydli, 16:9 formatdagi taqdimot.
- `qisqa-qollanma.pdf` — bir A4 sahifalik auditoriya qo‘llanmasi.
- `../portable/cyber-university.html` — bitta fayldan iborat interaktiv sayt.

Windows’da ZIP arxivni avval to‘liq ajrating. `portable` papkasidagi `cyber-university.html` faylini Edge yoki Chrome’da oching. Buning uchun Node.js yoki terminal kerak emas. PDF fayllarni Edge yoki odatiy PDF o‘quvchida ochish mumkin.

Agar faylni GitHub’da ko‘rayotgan bo‘lsangiz, uni kompyuterga yuklab oling; HTML manba matnini ko‘rish saytni ishga tushirmaydi. Bu fayllarning mavjudligi sayt ommaviy domenida e’lon qilinganini anglatmaydi.
